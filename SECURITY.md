# Security Policy

## Supported versions
This repository is provided as an educational reference. Security fixes are applied to the default branch as needed.

## Reporting a vulnerability
If you discover a security issue, **do not open a public GitHub issue**.

Please report privately by emailing the repository owner or opening a private security advisory in GitHub.

Include:
- A clear description of the issue and impact
- Steps to reproduce / proof-of-concept (if safe)
- Any suggested remediation

## Data handling (critical)
This repo must **never** contain:
- Real customer/CRM exports
- Names, emails, phone numbers, addresses, VINs, device identifiers, or any other personal data
- API keys, tokens, credentials, or private keys

Use the app's **Demo mode** (synthetic leads) or generate sanitized sample data for sharing.
